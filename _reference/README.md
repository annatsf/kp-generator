# Как перезапустить генератор КП на новом месте

Короткая памятка на случай переноса инструмента (бэкап-версия в этом репозитории).

## Что это

Статический сайт — только HTML \+ CSS \+ JS, без сервера и без сборки. Он читает данные из Google-таблиц через Google Sheets API и формирует коммерческое предложение (форматы: Презентація, Документ, Документ з малюнками). Весь код, нужный для работы, уже лежит в этом репозитории — он автоматически зеркалится из оригинала раз в сутки (workflow `.github/workflows/mirror.yml`).

## Что в папке \_reference

Эта папка синком НЕ затирается, поэтому здесь безопасно хранить:

- снимок реального расчётного файла (пример данных);  
- шаблон расчётного файла (пустая структура вкладок).

## Живые источники данных (Google Sheets)

Шаблон расчётного файла: [https://docs.google.com/spreadsheets/d/1g\_ICKAssywjzinoyrvTAl9fQ7WbJQHLqj1vasJtuqRU/edit](https://docs.google.com/spreadsheets/d/1g_ICKAssywjzinoyrvTAl9fQ7WbJQHLqj1vasJtuqRU/edit)

Вкладки, из которых берутся данные (их точные названия заданы в `js/config.js`):

- **ПДВ** — позиции и суммы (вариант с ПДВ).  
- **Готівка\_ФОП** — то же для варианта без ПДВ (в интерфейсе это переключатель «ПДВ» / «C»).  
- **Моделювання Фін. показників роботи СЕС** — финпоказатели; курс USD в ячейке **L2**; генерация и диаграмма.  
- **Кошторис\_Наявність обладнання** — расшифровка комплектующих (для «Розширеного бюджету»).

## Шаги запуска на новом месте

### 1\. Свой Google API-ключ

Сейчас в коде зашит ключ фирмы (`js/config.js`, поле `GOOGLE_API_KEY`). На новом месте нужен свой:

1. Google Cloud Console → создать проект.  
2. Включить **Google Sheets API** (только чтение).  
3. Создать API key. Ограничить его:  
   - Application restrictions → HTTP referrers → добавить свой новый домен.  
   - API restrictions → выбрать только Google Sheets API.  
4. Вписать свой ключ в `js/config.js` → `GOOGLE_API_KEY`.

Примечание: старый ключ, скорее всего, ограничен доменом `escoreodessa.github.io`, поэтому на новом адресе работать не будет — свой ключ обязателен.

### 2\. Свои расчётные таблицы

1. Сделать копию шаблона (ссылка выше) на свой Google Drive.  
2. Открыть доступ «Просмотр по ссылке» (чтобы API-ключ мог читать таблицу).  
3. Если реальные названия вкладок отличаются — поправить их в `js/config.js` (поля `SHEET_TAB_*`).

### 3\. Хостинг (сделать сайт живым)

Проще всего — **Netlify** или **Cloudflare Pages** (бесплатные):

- Подключить этот репозиторий → сайт публикуется автоматически.  
- Работают с приватным репозиторием, можно привязать свой домен.

Альтернатива — **GitHub Pages**, но бесплатно только из **публичного** репозитория (тогда код и API-ключ видны публично). Для приватного нужен платный GitHub Pro. Поэтому для приватной копии Netlify/Cloudflare удобнее.

### 4\. Проверка

Открыть опубликованный сайт → вставить ссылку на свою расчётную таблицу → сгенерировать КП. Если данные не подтягиваются — почти всегда причина одна из двух: неверный домен в ограничениях API-ключа, либо у таблицы нет доступа «по ссылке».
